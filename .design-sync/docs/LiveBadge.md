Tally-red "LIVE" tag with a white lamp; takes no props (text comes from i18n, needs `ReplaymarkProvider`). Put it next to a streamer name for streams that are currently live.

## Example

```jsx
<div className="flex items-center gap-2"><span className="font-display text-xl font-bold">Gronkh</span><LiveBadge /></div>
```
